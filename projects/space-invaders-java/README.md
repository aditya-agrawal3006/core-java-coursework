# Space Invaders (Java)

An arcade-style game built with Java AWT, using object-oriented classes for the spaceship, asteroids, projectiles, movement and collision handling.

## Technologies
- Java
- Standard JDK libraries

## Code
- Main implementation: [`src/game/SpaceInvaders.java`](src/game/SpaceInvaders.java)

## Running locally

Compile and run from the repository root using a JDK:

```bash
javac -d out $(find src -name '*.java')
java -cp out game.SpaceInvaders
```

## Project background

Developed as part of University of Maryland programming coursework. Some scaffolding or interfaces were provided with the assignment; this repository preserves the project structure for review.
