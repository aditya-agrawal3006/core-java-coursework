# Core Java Projects

Selected Java projects from my object-oriented programming coursework at the University of Maryland. Organized by application rather than course number.

| Project | Focus |
| --- | --- |
| [Space Invaders](projects/space-invaders-java/) | Java AWT, OOP, movement and collision handling |
| [Concurrent Order Processor](projects/concurrent-order-processor/) | Multithreading, shared state, synchronization |
| [Graph Algorithms](projects/graph-algorithms-java/) | Graph traversal and shortest paths |
| [Online Exam System](projects/online-exam-system/) | OOP, collections, question types, grading |

Each directory contains a project-specific README and the source files needed to understand the implementation. The order processor also includes a small example input dataset.

**Note:** These are coursework projects; parts of the specifications, scaffolding, or interfaces were provided by the course. The online exam system has not been fully verified against all saved reference outputs.
